# Items, TMs and HMs

**Items** in the desktop menu and phone navigation has two modes:

- **Items** — search all 1,883 items by name or effect text, filter by category (Poké Balls, Medicine, Evolution, Held items, Mega Stones, Z-Crystals, Tera Shards, Materials, Picnic, Quest…) and by the generation the item appears in. Each entry shows its category, short effect, available generations, Fling power and coin cost where recorded.
- **TMs & HMs** — pick any game and list its full machine table (TM01…, HM01… and Sword/Shield's TRs) with the move each teaches and the move's type. The list is searchable by move name, machine number or item name.

## Data

`src/data/items.generated.ts` is generated by `scripts/generateItemsData.mjs` from PokéAPI's canonical CSVs: `items`, `item_names`, `item_categories`, `item_prose`, `item_game_indices`, `machines`, `moves`, `move_names` and `version_groups`. A dozen downloads replace thousands of API calls, and nothing is fetched at runtime, so the data ships with the app and the offline package.

`src/data/gameVersionGroups.ts` maps each canonical game to its PokéAPI version group so a game shows the correct machine list. Legends: Arceus and Pokémon GO have no TM/HM machines and are labelled as such.

## Map pickups

Curated evolution and key-item locations from `src/data/pokemonItemsData.ts` are surfaced in map location panels as **Items found here**. The lookup matches a location name without its "City/Town/Village/Island/Park/Mountain/Route" suffix, so Celadon City lists the Celadon Department Store pickups.

## Dynamax Crystal names

The 300 Dynamax Crystals are stored with their official names, which are real star
designations using the IAU constellation abbreviations (And = Andromeda,
Sgr = Sagittarius, PsA = Piscis Austrinus). Those are accurate but unreadable, so
`humanItemName()` expands every one to a plain name such as
**"Dynamax Crystal — Sagittarius 6879"**, and the Items page searches and sorts by that
readable form (search "Ursa Major" to find them). Unknown or non-crystal names are
returned unchanged.

## Accuracy and scope

Item names, effects, categories, generations, TM/HM tables and move/type data are PokéAPI's. **Per-area pickup tables (which Poké Ball sits in which grass patch) are not part of that dataset.** Exact find spots are therefore only shown where the app already curates them (evolution items and key items) and appear in the map panels; the Items page does not invent locations. Machine numbering follows the version group, so a game's list matches its own generation.

## Tests

`npm run test:items` checks the item/machine tables, game mapping and labels, then drives the real app: item search, category and generation filters, the HeartGold HM01 → Cut lookup, the Surf search, map pickup notes and phone layout.
